# EnterprisePilot AI - Demo Project

EnterprisePilot AI is an AI-powered enterprise operations copilot designed for complex inventory and warehouse workflows.

## Features
- **AI Copilot**: Integrated chat for inventory analysis and automated workflows.
- **Warehouse Operations**: Real-time zone efficiency tracking and Kanban dispatch.
- **Inventory Management**: SKU-level tracking with AI-driven risk profiling.
- **Analytics Hub**: Predictive insights and trend visualization.
- **Role-Based Access**: Specialized views for Admin, Manager, and Staff.

## Tech Stack
- React / Vite
- Tailwind CSS
- Lucide React Icons
- React Router
